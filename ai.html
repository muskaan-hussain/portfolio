V · AI in construction

Teaching the tools to see.

Technology in construction is the area I am most passionate about: the small automations that take the repetition out of CM and BIM work, built so the output stays transparent and the project data stays private.

Why I build this
Having worked both on site and on the technology side, I want to bridge the two, so what is built in the model and what happens in the field stay connected.
01
Build the small tools

Teams run powerful software and never touch the automation already inside Excel, Revit, APIs and scripts. Small fixes, repeated across teams and months, add up.

02
Use AI to build, not to run

AI helps me test logic and write a VBA command, Python script, Dynamo workflow or Revit API tool. The finished tool runs on its own, as code.

03
Keep project data private

Because the tools run independently, nothing sensitive has to leave the project to reach an external AI.

04
Scale what works

A workflow that saves one project engineer an hour becomes valuable when it is refined and used across teams and projects.
